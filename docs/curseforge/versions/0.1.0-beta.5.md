<h2>v0.1.0-beta.5</h2>

<p>Adds a Spanish (<code>es_es</code>) locale for <strong>Apothic Attributes</strong>, on top of the
0.1.0-beta.4 pack. No asset-fix or Patchouli changes.</p>

<h3>Added &mdash; Spanish locale for Apothic Attributes (161 keys)</h3>

<p>Apothic Attributes ships an <code>es_es.json</code>, but it is stale: it was written for an older
build and its keys no longer match the ones the current mod version (2.10.1) looks up. Every one of
the 161 live keys fell through to English in-game &mdash; attribute names on gear, their Shift
tooltips, the custom status effects and their potions, and the combat death messages. The pack now
supplies those 161 keys, merged on top of the mod's own (outdated) file.</p>

<ul>
<li><strong>Attributes</strong> &mdash; names and one-line descriptions for
<em>Armor Pierce / Shred</em>, <em>Prot. Pierce / Shred</em>, <em>Crit Chance / Damage</em>,
<em>Cold / Fire / Current-HP / Arrow / Projectile Damage</em>, <em>Life Steal</em>,
<em>Overheal</em>, <em>Ghost Health</em>, <em>Draw Speed</em>, <em>Mining Speed</em>,
<em>Arrow Velocity</em>, <em>Dodge Chance</em>, <em>Experience / Healing Received</em>,
<em>Cooldown Reduction</em>, <em>Elytra / Creative Flight</em>.</li>
<li><strong>Vanilla &amp; NeoForge attribute descriptions</strong> &mdash; the <code>.desc</code>
lines added to Armor, Attack Damage/Speed/Knockback, Luck, Max Health, Movement Speed, Block/Entity
Reach, Step Height, Swim Speed, Gravity, and the vanilla potion effects.</li>
<li><strong>Custom status effects</strong> &mdash; <em>Bleeding</em>, <em>Bursting Vitality</em>,
<em>Ancient Knowledge</em>, <em>Grievous Wounds</em>, <em>Sundering</em>, <em>Detonation</em>,
<em>Flying</em>: effect name, tooltip and description, plus the
potion / splash potion / lingering potion / tipped arrow item names for each.</li>
<li><strong>Death messages</strong> &mdash; Bleeding, Detonation, Current-HP, Fire and Cold damage
sources (item and player variants).</li>
<li><strong>Attributes screen</strong> &mdash; the <em>Hold Shift</em> / base / min / max / modifier
/ formula GUI strings.</li>
</ul>

<h3>Notes</h3>

<ul>
<li>Terminology was aligned, where the mod's stale file still had usable Spanish, with its previous
choices (<em>Sundering</em> &rarr; &laquo;Resquebrajadura&raquo;, <em>Knowledge</em> &rarr;
&laquo;Sabidur&iacute;a&raquo;, <em>Bleeding</em> &rarr; &laquo;Sangrado&raquo;).</li>
<li>The <code>&#8987;</code> cooldown glyph, all <code>%s</code> / <code>%1$s</code> format
specifiers and the <em>Eterna / Quanta / Arcana</em>-style proper nouns are preserved verbatim.</li>
<li>Translation done with OpenCode (MiMo-V2.5); key integrity, placeholders and JSON validity
verified with a script.</li>
</ul>
