<h2>v0.1.0-beta.10</h2>

<p>Quality pass over the beta.1 machine translation &mdash; <strong>batch 5: Ars Nouveau</strong>
(<code>ars_nouveau</code>, 921 keys). 255 strings fixed; the bulk is the sound / particle picker.</p>

<h3>Fixed &mdash; Ars Nouveau Spanish</h3>

<ul>
<li><strong>Sound &amp; particle labels (219 strings) rewritten.</strong> The MT had produced literal
word-salad for Ars Nouveau's sound/particle config &mdash; &laquo;Bloque de Amatista Romper&raquo;,
&laquo;Harified de Hueso Usar&raquo;, &laquo;Popped de Carga Sculk&raquo;, &laquo;Aplicar Efecto
Omen de Asalto&raquo;. Now natural Spanish label phrases with correct word order
(&laquo;Romper bloque de amatista&raquo;, &laquo;Usar harina de huesos&raquo;, &laquo;Estallido de
carga de sculk&raquo;, &laquo;Aplicar efecto presagio de incursión&raquo;), vanilla mob names, and
Spanish sentence case.</li>
<li><strong>Terminology (glossary &sect;2.2):</strong> <em>Archwood</em> was translated as
&laquo;Madera Arcana&raquo; / &laquo;Bosque Arcano&raquo; in the block, item and guidebook strings
&rarr; kept as <em>Archwood</em> / &laquo;bosque de Archwood&raquo;.</li>
<li><strong>Vanilla terms:</strong> <em>Brewing Stand</em> left untranslated in two aliases &rarr;
&laquo;Soporte para pociones&raquo;; &laquo;Toque de Seda&raquo; &rarr; &laquo;Toque de seda&raquo;
in ~22 augment descriptions.</li>
<li>Minor: &laquo;Conversión Alakarkinos&raquo; &rarr; &laquo;Conversión de Alakarkinos&raquo;;
&laquo;Hacia la LUNA&raquo; &rarr; &laquo;Hacia la luna&raquo;; a few mid-sentence capitalization
fixes.</li>
</ul>
