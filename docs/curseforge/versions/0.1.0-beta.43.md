<h2>v0.1.0-beta.43</h2>

<p>Cleanup release &mdash; removes Spanish overlays for <strong>8 Stalking Dragons mods</strong>
whose translations now live in the mods themselves.</p>

<h3>Removed</h3>

<ul>
<li><code>assets/&lt;namespace&gt;/lang/es_es.json</code> for <code>vellumli</code>,
<code>teleport_animation</code>, <code>skd_menu</code>, <code>data_miner</code>,
<code>info_tab</code>, <code>carry_mechanics</code>, <code>regalia_slots_api</code>,
<code>workhand_tools</code>.</li>
<li>This resource pack is for third-party mods that ship no or partial Spanish. These eight are our
own mods &mdash; their Spanish locale (with the QA-pass corrections applied) has been committed to
each mod's own repository, so it ships with the mod and no longer needs an overlay here.</li>
</ul>

<h3>Notes</h3>

<ul>
<li>84 third-party namespaces remain. The translation QA (betas 6&ndash;42) continues on those.</li>
<li>Until each affected mod publishes its next build, the moved keys will only be present via that
mod's source; existing in-jar locales are unchanged.</li>
</ul>
