<h2>v0.1.0-beta.1</h2>

<p>The project is now <strong>Mystical Realms Translation &amp; Fixes</strong> (renamed from
<em>Mystical Realms Resource Pack</em> to fit CurseForge's resource-pack category rules). Same project,
same download slot &mdash; it now also carries Spanish translations, not just asset fixes.</p>

<h3>Added &mdash; Spanish (es_es) translations</h3>

<p>Spanish locale files for <strong>101 mod namespaces</strong> (~12,515 keys), sourced from each mod's
own <code>en_us.json</code>. Minecraft merges these on top of whatever each mod already ships, so mods
that already had a partial Spanish locale only receive the keys they were missing &mdash; nothing that
was already translated is overwritten.</p>

<ul>
<li><strong>59 mods with no prior Spanish locale</strong>, including: Every Compat, Butchery,
Macaw's Roofs, Reliquary, Xaero's World Map, Tom's Simple Storage, Bookshelf, ModernFix, Spell Power,
BCLib, Caravans, Farmer's Sandwiches, Ace's Spell Utils, More Villagers, Iron's Spells Lib,
Inventory Essentials, Mystical Automation, Not Enough Crashes, Crafting Tweaks, Balm, IDAS,
Integrated Stronghold, Moog's structures, TerraBlender and more.</li>
<li><strong>42 mods with an incomplete Spanish locale, now completed</strong>, including:
Supplementaries (+1055 keys), Ars Nouveau (+921), Xaero's Minimap (+522), Iron's Spells 'n Spellbooks
(+475), BetterEnd (+367), Quark (+324), Dawn of Time (+275), Waystones (+263), Moonlight Lib (+239),
Farmer's Delight (+193), JEI (+188), Create (+178), Armor of the Ages (+161), Enchantment Descriptions
(+151), Sophisticated Backpacks (+149), Deeper and Darker (+136), Biomes O' Plenty (+119), Jade (+105),
Corail Tombstone (+72), Embeddium (+71), L_Ender's Cataclysm (+61), Guard Villagers (+59).</li>
</ul>

<h3>Fixes (unchanged from 0.0.0-beta.1)</h3>

<ul>
<li><strong>Butchery <code>ravager_carcass</code> model</strong>: replaces an orphan model file with an
illegal <code>-90</code> element rotation by the mod's own corrected sibling model. Silences a startup
<code>ERROR</code> from Minecraft's bulk model loader. No in-game visual change.</li>
</ul>
