<h2>v0.1.0-beta.3</h2>

<p>Adds Spanish (<code>es_es</code>) translations for three more mod namespaces on top of the
0.1.0-beta.2 pack. No asset-fix changes.</p>

<h3>Added &mdash; Spanish translations (~520 keys, 3 namespaces)</h3>

<p>Source text is each mod's own <code>en_us.json</code>. Minecraft merges these <code>lang</code>
files over whatever the mod already ships. Closes the real translation gaps found while snapshotting
modpack v5.134.4.</p>

<ul>
<li><strong>Apothic Enchanting</strong> 1.6.2 &mdash; <code>apothic_enchanting</code>, 425 keys.
Block names (Hellshelf / Seashelf / Deepshelf / Endshelf variants&hellip;), the enchanting-table GUI,
tooltips and descriptions. The Apotheosis stat proper nouns (<code>Eterna</code>, <code>Quanta</code>,
<code>Arcana</code>) and the Roman-numeral level names are kept untranslated.</li>
<li><strong>Apothic Spawners</strong> 1.4.0 &mdash; <code>apothic_spawners</code>, 89 keys. Spawner
statistics, tooltips and the <em>Capturing</em> enchantment.</li>
<li><strong>Placebo</strong> 9.9.2 &mdash; <code>placebo</code>, 6 keys (commands and cosmetic
supporter toggles).</li>
</ul>

<p>Pack total: <strong>104 namespaces</strong>, ~13k keys.</p>
