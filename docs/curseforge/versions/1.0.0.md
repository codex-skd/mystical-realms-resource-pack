<h2>v1.0.0 - Initial release</h2>

<h3>Added</h3>
<ul>
<li>First versioned release of the <strong>Mystical Realms Resource Pack</strong> for Minecraft 1.21.1.</li>
<li><strong>Butchery <code>ravager_carcass</code> fix</strong>: Butchery 5.2 ships an orphan model file
(<code>assets/butchery/models/custom/ravager_carcass.json</code>) with an illegal element rotation
(<code>angle: -90</code>; only &plusmn;45 / &plusmn;22.5 / 0 are valid). Nothing references it, but
Minecraft 1.21 bulk-loads every <code>models/**/*.json</code> at startup and logs a parse
<code>ERROR</code> for it. This pack replaces the file with the mod's own already-fixed sibling model
(<code>custom/ravager_carcas.json</code>), so the load succeeds and the log stays clean.
<strong>No in-game visual change</strong> &mdash; the placed carcass uses a code-based model and the
carcass item uses <code>custom/ravager_carcas</code>.</li>
</ul>
