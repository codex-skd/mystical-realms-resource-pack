<h2>v0.1.0-beta.6</h2>

<p>First batch of a <strong>quality pass</strong> over the machine-translated Spanish locale from
beta.1. This release fixes the <strong>Waystones</strong> namespace (263 keys); more namespaces
follow in later betas.</p>

<h3>Fixed &mdash; Waystones Spanish (190 of 263 strings rewritten)</h3>

<ul>
<li><strong>&laquo;Mojón&raquo; removed.</strong> The MT rendered <em>Waystone</em> as
&laquo;mojón&raquo;, which in European Spanish reads as a vulgarism. Per project decision the word
<em>Waystone</em> is now kept untranslated, and so is the <code>-stone</code> family
(<em>Portstone</em>, <em>Sharestone</em>, <em>Warpstone</em>). Descriptive items are translated:
<em>Warp Plate</em> &rarr; &laquo;Placa de traslado&raquo;, <em>Warp Portal</em> &rarr;
&laquo;Portal de traslado&raquo;, <em>Bound / Return Scroll</em> &rarr; &laquo;Pergamino
vinculado / de regreso&raquo;.</li>
<li><strong>Vanilla terminology.</strong> <em>Blackstone</em> &laquo;Negrita&raquo; &rarr;
&laquo;piedra negra&raquo;; <em>Nether</em> &laquo;Inframundo&raquo; &rarr; &laquo;Nether&raquo;;
<em>Ender</em> &laquo;del Fin&raquo; &rarr; &laquo;del End&raquo;; colour names aligned with the
vanilla <code>es_es</code> (light blue &rarr; &laquo;azul claro&raquo;, etc.).</li>
<li><strong>Spanish capitalization.</strong> English Title Case removed from every block, item and
GUI string (&laquo;Piedra de Puerto Azul Claro&raquo; &rarr; &laquo;Portstone azul claro&raquo;).</li>
<li><strong>Gender consistency.</strong> The whole <code>-stone</code> family now agrees in the
feminine (&laquo;la Waystone&raquo;, &laquo;las Waystones activadas&raquo;, &laquo;Portstone
amarilla&raquo;).</li>
</ul>

<h3>Notes</h3>

<ul>
<li>Keys, placeholders (<code>%s</code>, <code>%d</code>, <code>%1$s</code>) and formatting codes
are unchanged; only values were touched. 73 strings were already correct and left as-is.</li>
<li>Pass done with OpenCode (MiMo-V2.5) against a ratified glossary
(<code>docs/GLOSARIO_ES.md</code>) with the vanilla 1.21.1 <code>es_es</code> as reference;
key integrity, placeholders and gender agreement verified with a script.</li>
</ul>
