<h2>v0.1.0-beta.36</h2>

<p>Cleanup release &mdash; removes Spanish locale folders for <strong>12 mods that are no longer in
the Mystical Realms modpack</strong>.</p>

<h3>Removed</h3>

<ul>
<li>Dead <code>assets/&lt;namespace&gt;/lang/es_es.json</code> overlays for mods that no longer ship
in the pack: <code>arssophisticatedcompat</code>, <code>ascendant_spawners</code>,
<code>caravans</code>, <code>common_toolkit</code>, <code>configured</code>,
<code>guardvillagers</code>, <code>horde_hoard</code>, <code>inventoryessentials</code>,
<code>mowzies_cataclysm</code>, <code>mowziesmobs</code>, <code>obscure_tooltips</code>,
<code>player_activity_view</code>.</li>
<li>These were carried over from the beta.1 audit; Minecraft ignores <code>lang</code> files for
namespaces with no mod, so this is a no-op in game &mdash; it just trims ~350 unused keys and keeps
the repo honest.</li>
</ul>

<h3>Notes</h3>

<ul>
<li>All remaining 93 namespaces were verified against the current modpack's jars. The by-batches
translation QA (betas 6&ndash;35) continues on the live namespaces.</li>
</ul>
