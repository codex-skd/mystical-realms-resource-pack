<h2>v0.1.0-beta.4</h2>

<p>Adds Spanish (<code>es_es</code>) translations for the <strong>hardcoded Patchouli guidebooks</strong>
of three bundled mods, on top of the 0.1.0-beta.3 pack. No asset-fix or <code>lang</code> changes.</p>

<h3>Added &mdash; Spanish Patchouli guidebooks (188 files, ~779 strings)</h3>

<p>These guidebooks store their page text directly in JSON instead of language keys, so the pack's
<code>lang</code> layer never reached them and they showed up in English in-game even when the mod
ships an <code>es_es</code> locale. They are now injected as an <code>es_es/</code> book folder
alongside the mod's <code>en_us/</code> one &mdash; Patchouli prefers it and falls back to English
per file. Every Patchouli formatting code (<code>$(br)</code>, <code>$(l:...)</code>,
<code>$(#RRGGBB)</code>, <code>$(playername)</code>&hellip;) is preserved verbatim;
<code>type</code>/<code>icon</code>/<code>recipe</code> and resource locations are untouched.</p>

<ul>
<li><strong>Butchery</strong> &mdash; <code>butchers_guide</code>, 52 files (47 entries + 5
categories). Terminology matched to <code>butchery</code>'s own <code>es_es.json</code>
(<em>cleaver</em> &rarr; &laquo;Cuchillo de forjar&raquo;, <em>skinning knife</em> &rarr;
&laquo;Cuchillo de despiece&raquo;, <em>blood grate</em> &rarr; &laquo;Rejilla de sangre&raquo;).</li>
<li><strong>Apotheosis</strong> &mdash; <code>apoth_chronicle</code>, 126 files (107 entries + 19
categories).</li>
<li><strong>Iron's Spells 'n Spellbooks</strong> &mdash; <code>iss_guide_book</code>, 10 files
(9 entries + 1 category).</li>
</ul>

<h3>Notes</h3>

<ul>
<li>The book <em>title</em> and <em>landing page</em> of the Butchery and Iron's Spellbooks guides
live in <code>book.json</code> (data-pack territory, no <code>i18n</code>) and stay in English.
Apotheosis' book title is a language key and is already Spanish.</li>
<li><strong>Not included</strong>: BetterEnd's <code>guidebook</code> ships its own <code>es_es/</code>
folder; Ars Nouveau / Ars Elemental (<code>worn_notebook</code>) and Mystical Agriculture
(<code>guide</code>) use <code>i18n</code> keys already translated in their official locales.</li>
</ul>
